临床听力学与突发性耳聋居家测听研究综述（设计依据）

本系统在架构设计前系统调研了国际标准化组织测听规范（ISO 8253-1 / ISO 389）、中华医学会及美国耳鼻咽喉头颈外科学会（AAO-HNS）突发性耳聋临床实践指南，以及近年发表于 JMIR、Ear and Hearing、International Journal of Audiology 的移动/网页端自助纯音测听验证文献。核心工程化转化如下：

1. 为什么必须从 125 Hz 低频测起？（而非普通筛查 App 的 500/1000 Hz）

多数消费级听力筛查软件忽略 125 Hz 甚至 250 Hz。然而根据《突发性聋诊断和治疗指南 (2015)》，低频下降型突聋（耳蜗顶回膜迷路积水）专门累及 125–1000 Hz，患者往往表现为强烈耳闷胀感、堵棉花感或听自己说话有回音，而 2000 Hz 以上完全正常。本应用严格按照您的需求设计为 125 → 250 → 500 → 1000 → 2000 → 4000 → 8000 Hz 低频至高频递进测试，完整覆盖耳蜗从顶回到底回的全部毛细胞映射区。

2. 等响度/RETSPL 声学补偿与防削波谐波保护（ISO 389-1 / 389-8）

人耳在不同频率的听觉灵敏度差异巨大：在标准耳机耦合器下，0 dB HL 在 1000 Hz 仅需约 5.5–7 dB SPL，而在 125 Hz 则需要 26–45 dB SPL。若直接输出相同数字振幅，所有人测出的 125 Hz 都会呈现“假性低频耳聋”。此外，若低频正弦波触及数字满刻度（0 dBFS）发生削波（Clipping），会产生 375 Hz / 625 Hz 奇次谐波，导致低频聋患者误听到中频谐波而得出假正常结果。本引擎内置换能器 RETSPL 映射表与 -1.0 dBFS 零削波上限保护。

3. 改良 Hughson-Westlake 算法与脉冲/啭音抗耳鸣干扰（ISO 8253-1）

临床纯音测听金标准采用改良 Hughson-Westlake 升降法（听见降 10 dB，未听见升 5 dB，上升序列同级 ≥50% 命中定阈）。针对突聋患者高达 80% 伴随持续性耳鸣的痛点，文献证实三连脉冲音（Pulsed Tone，含 35ms 平滑上升/下降沿消除咔嗒瞬态频谱飞溅）与±5% 调频啭音（Warble Tone）能提供清晰的时域起止节律，显著降低把自身耳鸣误判为测试音的假阳性率。

4. 交叉听力（影子曲线）与对侧窄带掩蔽（Interaural Attenuation）

单侧中重度突聋测听时，当患耳给声强度超过健侧耳听阈 40–55 dB（耳间衰减值 IA）以上时，声波会振动颅骨直接传到对侧健康耳蜗，测出一条平行于健耳的假性“影子曲线”。本系统支持先测健耳建立个体生物学基线，并在双耳差值达到阈值时自动向健耳投送 1/3 倍频程窄带掩蔽噪声（NBN），并在听力图上规范标注临床掩蔽符号（右耳 △、左耳 □）。

居家纵向监测准确性最大化 5 条金律

  1. 固定同一副耳机与固定音量格数：居家复测最有价值的是观察“较前几天上升还是下降”。每次使用同一副入耳式或包耳式耳机、保持相同系统音量并配合「健侧耳 1000Hz 生物校准」，前后的相对误差可控制在 ±5 dB 级别。
  2. 避开低频家电底噪：测 125 Hz 和 250 Hz 时，请暂时关闭空调、空气净化器与风扇，深夜或安静卧室最佳。
  3. 宁缺毋滥，不要猜按：测试设有随机静默间隔（0.95–2.15秒），只有确定捕捉到微弱的“嘀-嘀-嘀”节律时才按键。
  4. 护耳第一，严禁大音量试探：突聋受损毛细胞常伴随“重振现象（Recruitment）”——小声听不见，声音稍大即震耳不适。切勿自行把系统音量开满。
  5. 出现波动立即就医：若连续两天发现相邻两频率阈值下移 ≥15 dB，或耳闷、眩晕加重，请第一时间前往医院耳鼻咽喉科复查，切勿延误调整方案时机。
